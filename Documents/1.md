Here is a step-by-step guide to downloading, modifying, and installing your own custom version of Aider without using `git clone`.

### Step 1: Download the Source Code
Since you do not want to use git to clone the repository, you can download the source code directly as a ZIP archive.

1.  Go to the **[Aider GitHub Repository](https://github.com/Aider-AI/aider)**.
2.  Click on the green **<> Code** button near the top right of the file list.
3.  Select **Download ZIP** from the dropdown menu.
4.  Save the file to your computer.

### Step 2: Extract and Prepare the Files
1.  Unzip the downloaded file (`aider-main.zip` or similar).
2.  Move the extracted folder to a location where you want to keep your custom project (e.g., `~/my-projects/custom-aider`).
3.  Open your terminal (Command Prompt, PowerShell, or Terminal) and navigate into that folder:
    ```bash
    cd path/to/custom-aider
    ```

### Step 3: Modify the Source Code
You can now modify the code. The core logic is typically located in the `aider/` subdirectory.

*   Open the folder in your code editor (like VS Code).
*   Make your desired changes to the Python files (e.g., changing prompts in `aider/coders/`, modifying logic in `aider/io.py`, etc.).

### Step 4: Install Your Custom Version
To use your modified version, you need to install it into your Python environment. The best way to do this while developing is using "editable" mode.

**Prerequisites:** Ensure you have Python 3.9+ installed.

1.  **Create a Virtual Environment (Recommended):**
    It is best practice to use a virtual environment so you don't mess up your system Python.
    ```bash
    # Create the environment
    python -m venv venv

    # Activate it
    # On Windows:
    venv\Scripts\activate
    # On macOS/Linux:
    source venv/bin/activate
    ```

2.  **Install in Editable Mode:**
    Run this command from the root of the unzipped folder (where `pyproject.toml` or `setup.py` is located):
    ```bash
    pip install -e .
    ```
    *   **`-e` (editable):** This flag tells pip to install the package in "editable" mode. Any changes you save to the source files will immediately be reflected when you run the `aider` command; you won't need to reinstall every time you change a line of code.
    *   **`.` (dot):** This tells pip to look for the package in the current directory.

### Step 5: Verify and Run
Once the installation finishes, you can check if it worked by running:

```bash
aider --version
```

To run your custom Aider on a project:
1.  Navigate to the git repository you want to edit with Aider.
2.  Run your custom tool:
    ```bash
    aider
    ```
    *(Note: If you used a virtual environment, you must activate it first, or use the full path to the executable, e.g., `path/to/custom-aider/venv/bin/aider`).*
